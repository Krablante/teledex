# Codez Stack

Teledex is one layer in the Codez ecosystem:

- [Codez](https://github.com/Krablante/codez): Codex-compatible runtime and App Server v2.
- [RTK Codex Plugin](https://github.com/Krablante/rtk-codex-plugin): optional shell/output safety.
- [Pitlane Codex Plugin](https://github.com/Krablante/pitlane-codex-plugin): optional code-navigation acceleration.
- Teledex: Telegram gateway and session layer.

Public Teledex installs require Codez App Server v2. Optional plugins can be
enabled later, but they are not required for the first local run.
