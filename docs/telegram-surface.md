# Telegram Surface

Teledex exposes a Telegram operator surface around Codez App Server v2 sessions.

Typical usage:

- Start a topic or private chat session.
- Send prompts and attachments.
- Watch progress updates.
- Use goal controls on app-server-v2 backed sessions.
- Receive final replies and generated files back in Telegram.

Only allowlisted Telegram users can control the gateway.
