# Teledex Guidebook

Teledex turns Telegram into a control surface for Codez App Server v2 sessions.

First run:

1. Install dependencies with `npm ci`.
2. Copy and fill `examples/teledex.env.example`.
3. Run `npm run doctor -- --env-file teledex.env`.
4. Start with `npm start -- --env-file teledex.env`.
