# Teledex Guidebook

Teledex превращает Telegram в управляющий слой для Codez App Server v2 sessions.

Первый запуск:

1. Установи зависимости через `npm ci`.
2. Скопируй и заполни `examples/teledex.env.example`.
3. Запусти `npm run doctor -- --env-file teledex.env`.
4. Стартуй через `npm start -- --env-file teledex.env`.
